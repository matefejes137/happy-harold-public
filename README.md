# Happy Harold — public website

Static site served by GitHub Pages (branch `main`, folder `/`).

| File | Purpose |
|---|---|
| `index.html` | Landing page (the Play Store "Website") |
| `privacy/index.html` | Privacy policy (HTML) — source text in `privacy/PRIVACY_POLICY.md` |
| `app-ads.txt` | Authorized ad sellers for AdMob; must be served at the **domain root** |
| `.nojekyll` | Serve files as-is |

Keep `privacy/index.html`, `privacy/PRIVACY_POLICY.md` and `docs/PRIVACY_POLICY.md` in the game repo in sync.
